# ISO 13485 条款生成与预筛矩阵

编制日期：2026-11-24。文档版本：1.0。状态：待业务复核，尚未实施。

本矩阵概括用户提供资料第 4—8 章的 72 个末级条款，不复制标准原文。按[规则总则](Iso13485Rules.md)确认来源和适用性，按[生成规则](Iso13485GenerationRules.md)编写，按[预筛规则](Iso13485PrescreenRules.md)处理证据和结果。

## 使用口径

- 每行是一个条款要求集合，后续可拆成带后缀的子规则；不是一条关键词判断，也不是必须新增一份文件。
- “生成要素”规定文件应描述什么；“预筛条件及证据”规定如何查找这些安排或实际记录。表中要素按适用条件逐项检查，不能用命中一两个词代替。
- 所有实际执行、数据真实性、批准有效性和活动有效性均保留人工取证事项；表内不再逐行重复这一边界。
- 程序描述安排、计划描述拟执行活动、记录描述已执行事实。某行涉及实际记录时，不意味着程序文件必须包含真实结果。
- 附带“适当时”“存在相应活动”“法规要求时”等条件必须保留。未知列待确认，已批准不适用单列，不能简单跳过。
- 标准要求与本项目具体表单字段、编号、格式和指标算法分开；后者是实现方式，不是标准统一格式。

## 4 质量管理体系

| 规则编号及主题 | 对象与适用条件 | 生成要素 | 预筛条件及证据 |
|---|---|---|---|
| R-4.1.1 体系与组织职能 | 质量手册及体系文件 | 文件化体系、保持有效性的安排、组织在适用法规下的职能、要求和活动的建立实施保持 | 核对组织实际职能、适用范围、法规识别及体系文件引用；泛称“符合标准”不足以满足 |
| R-4.1.2 过程识别与风险控制 | 体系过程描述 | 所需过程及应用范围、风险控制方式、过程顺序及相互作用 | 查过程清单、关系说明或图示引用、风险方法与适用过程的关系；不可只查“风险”一词 |
| R-4.1.3 过程运行与监测 | 各体系过程及其记录 | 控制准则和方法、资源信息、实施安排、监视测量分析及记录 | 要素须能关联到具体过程；记录或指标缺失列相应缺口，实际有效性取证 |
| R-4.1.4 体系过程变更 | 体系变更流程及记录 | 变更识别、对体系及所产器械的影响评价、控制和授权安排 | 查变更评价和控制要求；实际变更记录应对应具体影响，不以设计变更程序替代全部体系变更 |
| R-4.1.5 外包过程 | 存在影响产品符合性的外包时 | 保留组织责任、基于风险及外部方能力的监视控制、书面质量协议 | 查外包范围、协议及控制安排，关联 7.4；“全部外包所以不适用”不能成立，是否实际外包先确认 |
| R-4.1.6 体系软件确认 | 使用质量管理体系软件时 | 文件化程序、初次使用前确认、适当的变更或应用后再确认、风险相称方法及记录 | 查软件与用途清单、确认安排及结果索引；未知软件用途列待确认，不以供应商宣传等同于确认记录 |
| R-4.2.1 文件体系 | 体系文件清单或结构 | 质量方针目标、手册、所需程序和记录、组织所需文件、法规要求的其他文件 | 以适用要求核对承载关系；不要求固定份数，也不按标准章节强制拆分文件 |
| R-4.2.2 质量手册 | 质量手册 | 范围、实际删减或不适用的说明理由、程序或引用、过程关系、文件结构 | 五类内容逐组检查；无删减时可明确说明，不能强迫生成虚构删减；理由充分性人工核对 |
| R-4.2.3 医疗器械文件 | 每个器械类型或器械族 | 总体描述及预期用途、标签使用说明、产品规范、生产包装贮存处理销售、监视测量、适用安装服务文件或引用 | 可由一个或多个文件或受控索引承载；逐项关联器械类型，引用未提供列待补；不是单纯质量手册替代 |
| R-4.2.4 文件控制 | 文件控制程序、受控文件及清单 | 发布前评审批准、更新再批准、修订识别、使用处版本、清晰识别、外来文件、退化遗失防护、旧版防误用、更改批准及旧版保存 | 对控制安排逐项取证；封面字段只支持识别；至少一份作废文件及保存条件单独核对；批准真实性与正式状态人工取证 |
| R-4.2.5 记录控制 | 记录程序及各类记录 | 标识贮存、安全完整、检索、保存、处置、健康信息保密、清晰可识别、变更可识别；寿命期、放行日起两年及适用法规关系 | 检查控制要素、对象和保存起算依据；未提供寿命期或法规时不能凭“两年”算完整；记录变更不得覆盖原痕迹 |

## 5 管理职责

| 规则编号及主题 | 对象与适用条件 | 生成要素 | 预筛条件及证据 |
|---|---|---|---|
| R-5.1 管理承诺 | 方针、目标、评审及资源安排 | 最高管理者传达顾客法规要求、制定方针、确保目标、管理评审、资源保障 | 查相应安排和实际证据索引；仅有承诺口号不足以证明活动实施 |
| R-5.2 顾客关注 | 顾客要求识别和管理安排 | 顾客要求及适用法规的确定和满足职责、与实现过程的接口 | 关联需求、评审及反馈依据；不能仅凭满意度问卷替代全部要求识别 |
| R-5.3 质量方针 | 质量方针及沟通评审安排 | 适合组织宗旨、满足要求和保持体系有效性承诺、目标框架、沟通理解及持续适宜性评审 | 方针文本与目标框架可定位；实际沟通、理解和评审另取证，不生成已理解的虚构记录 |
| R-5.4.1 质量目标 | 各有关职能和层次的目标 | 产品和法规相关目标、可测量性、与方针一致；组织选定评价方式和职责 | 查目标定义、测量口径及相关范围；未知基线、目标值或达成值不得猜填 |
| R-5.4.2 体系策划 | 体系建立及变更策划 | 满足目标和 4.1 要求的策划、变更时保持体系完整性 | 查策划与过程、目标及变更影响的关系，不以项目进度表代替全部体系策划 |
| R-5.5.1 职责和权限 | 组织职责文件 | 职责权限文件化和沟通、影响质量的管理执行验证人员关系、所需独立性和权限 | 查岗位和决策权限、接口、必要独立性安排；姓名列表不能替代职责界定 |
| R-5.5.2 管理者代表 | 管理者代表的指定及职责 | 指定的管理成员、过程文件化、向最高管理者报告有效性及改进需求、提高法规体系意识 | 查指定依据、职责和报告路径；正式指定和授权真实性人工核实 |
| R-5.5.3 内部沟通 | 内部沟通安排 | 合适的沟通过程、体系有效性信息沟通、责任和渠道 | 查沟通内容及过程线索；不强制采用某种会议形式或软件 |
| R-5.6.1 管理评审安排 | 评审程序、计划和记录 | 文件化程序、已策划间隔、最高管理者评审、适宜充分有效性、改进及方针目标变更、保存记录 | 程序和实际评审分开检查；不把每年一次当成统一标准频次 |
| R-5.6.2 管理评审输入 | 评审程序及每次评审资料 | 反馈、投诉处理、监管报告、审核、过程监测、产品监测、纠正、预防、以前跟踪、体系变更、改进建议、新修订法规，共十二类 | 程序逐类规定；实际记录逐类关联来源或当期无事项的评价说明；不能凭“输入”标题通过 |
| R-5.6.3 管理评审输出 | 评审程序及记录 | 体系及过程有效性等改进、顾客相关产品改进、法规变化所需变更、资源需求的决定措施及记录 | 逐类核对输出及输入关联；责任跟进方式由组织安排；不生成并未作出的管理决定 |

## 6 资源管理

| 规则编号及主题 | 对象与适用条件 | 生成要素 | 预筛条件及证据 |
|---|---|---|---|
| R-6.1 资源提供 | 资源策划和管理安排 | 实施并保持体系有效、满足顾客和适用法规所需资源的确定及提供 | 查资源需求与人员设施信息等安排的关系；真实资源可用性需取证 |
| R-6.2 人力资源 | 能力及培训程序和记录 | 教育培训技能经验、能力要求、培训或其他措施、效果评价、工作相关性和质量目标意识、能力记录 | 区分培训出席与有效性评价；方法与风险相称，不能仅用签到证明胜任 |
| R-6.3 基础设施 | 设施设备及维护文件 | 达到产品要求、防混淆、有序处理；适当的场所设备支持服务；影响质量的维护要求频率及记录 | 查设施范围和维护依据，适用项逐个核对；不虚构设备台账或固定维护周期 |
| R-6.4.1 工作环境 | 环境程序及影响安全性能的接触条件 | 工作环境要求；必要的监视控制；适用的健康清洁服装；特殊环境临时人员胜任或监督 | 查环境条件与产品质量关系、人员控制及监测记录引用；不预设每个产品必须有洁净室 |
| R-6.4.2 污染控制 | 污染风险适当时；无菌器械有专用条件 | 已污染或潜在污染产品控制；无菌器械微生物或微粒控制及装配包装清洁度 | 先确认产品与活动，分别检查一般污染和无菌专用；非无菌不等于所有污染要求不适用 |

## 7 产品实现

| 规则编号及主题 | 对象与适用条件 | 生成要素 | 预筛条件及证据 |
|---|---|---|---|
| R-7.1 实现策划及风险管理 | 产品实现计划、风险管理过程及记录 | 与体系一致的过程；文件化风险管理及记录；产品目标要求、过程文件资源、验证确认监测检验储运追溯及接收准则、所需记录 | 查各项策划和风险过程证据；风险细化方法按另行确认依据，不将“剩余风险”关键词说成本文条款的全部原文要求 |
| R-7.2.1 产品要求确定 | 顾客需求、技术输入及调研资料 | 顾客明示及交付后要求、预期用途必需要求、适用法规、安全性能所需用户培训、组织附加要求 | 按来源区分要求、用途、培训和法规线索，未知要求列待补；不以调研模板替代已确认需求 |
| R-7.2.2 产品要求评审 | 合同订单及其更改评审 | 承诺提供前评审、要求文件化、差异解决、法规、培训可用性及履约能力、未成文需求确认、变更文件通知和记录 | 查具体订单或要求版本与评审关系；仅有签约日期不足以证明评审充分或发生在承诺前 |
| R-7.2.3 顾客及监管沟通 | 沟通安排和记录 | 产品信息、问询合同订单变更、反馈投诉、忠告性通知；依法规与监管机构沟通 | 逐类查渠道职责及资料；法规沟通不自动等同于每起投诉都需报告 |
| R-7.3.1 设计开发程序 | 设计开发适用时 | 文件化的设计开发控制程序，衔接各阶段及相关活动 | 查控制程序或明确引用；仅有项目计划不能自动替代设计控制程序 |
| R-7.3.2 设计开发策划 | 设计计划，随进展适当更新 | 阶段、阶段评审、验证确认转换、职责权限、输出到输入追溯方法、含人员能力的资源 | 六类策划逐项核对；计划未来日期允许，不要求此文件承载全部阶段实际成果 |
| R-7.3.3 设计开发输入 | 设计输入及其评审记录 | 用途相关功能性能可用性安全、法规标准、风险输出、适当类似设计信息、其他必需要求；充分适宜评审批准、完整明确可验证且无矛盾 | 查输入来源和评审证据及可追溯性；数值和法规缺依据列待补，实质冲突列待核对 |
| R-7.3.4 设计开发输出 | 输出文件及批准记录 | 满足输入、采购生产服务信息、接收准则、安全正常使用特性、便于输入验证的形式、发布前批准和记录 | 查输入输出关系和输出版本、接收准则；只有图纸目录不等于输出完整 |
| R-7.3.5 设计开发评审 | 各适当阶段的评审计划和记录 | 按策划系统评审、评价满足要求能力、识别措施、相关职能及专家参与、结果和措施记录 | 查阶段、参加角色、议题及结论措施关联；不自动填“评审通过” |
| R-7.3.6 设计开发验证 | 验证计划和记录 | 方法、接收准则、适当的统计抽样依据；输出满足输入；预期连接接合情形；结果结论及措施记录 | 区分验证与确认，追溯每项输入及适用接口；未经验证的数据不编造 |
| R-7.3.7 设计开发确认 | 确认计划和记录 | 满足用途；方法准则及适当统计依据；代表性产品及选取理由；依法规临床或性能评价；适用连接接合；交付使用前完成；记录 | 查用途、代表性对象、评价依据与完成时点；用于评价的产品不算已放行给顾客，适用临床要求需确认 |
| R-7.3.8 设计开发转换 | 转换程序及结果 | 输出转制造的文件化程序、成为最终生产规范前的适用生产验证、生产能力、结果结论记录 | 查设计输出版本到生产规范及能力验证的关联，不将一次培训或交接签收当成全部转换证据 |
| R-7.3.9 设计开发更改 | 变更程序和记录 | 识别重要性；实施前评审验证、适当确认及批准；对组件、在制或已交付产品、风险及实现过程影响；结果措施记录 | 查变更对象、前后版本、时序及影响评价；不简单按“变更”标题算完成 |
| R-7.3.10 设计开发文件 | 每个器械类型或器械族 | 包含或引用满足设计要求及设计变更的记录，保持可追溯索引 | 按类型或器械族核对设计记录集合；有设计计划不足以替代全套记录 |
| R-7.4.1 采购过程 | 采购程序、供应商评价及监视记录 | 采购要求控制、供方能力绩效、产品质量影响及风险、选择评价、监视再评价、不满足要求处置和记录 | 逐项查评价准则和活动记录关系；合格供应商名录不能替代评价与持续监视 |
| R-7.4.2 采购信息 | 订单、规范及相关协议 | 产品描述或引用，适当的规范接收程序设备人员资质和体系要求，沟通前充分适宜，适当变更提前通知协议，按追溯程度保留信息 | 查采购对象和版本、批准或确认、适用变更通知及追溯；不强迫每个订单重复全部体系要求 |
| R-7.4.3 采购产品验证 | 进货验证安排及记录 | 检验或其他验证、范围与供方评价及风险相称、采购变更影响评价、适用现场验证和放行安排、记录 | 查对象、依据、方法及结果；未知抽样量不补造，不将每批全检当成统一规定 |
| R-7.5.1 生产和服务控制 | 生产服务过程及每台或批记录 | 策划实施监视控制；适当程序、设施、参数特性、测量装置、标签包装、放行交付后活动；数量、追溯、验证批准的记录 | 查过程安排及生产数量、批准销售数量和追溯线索；不能用空白批记录证明已生产合格 |
| R-7.5.2 产品清洁 | 符合条款列明清洁情形时 | 清洁或污染控制要求、灭菌或使用前清洁、非无菌但清洁关键、不可再清洁场景、去除加工助剂；适用的清洁前环境例外 | 逐项确认触发事实；非无菌不能自动排除，是否适用及例外不能只凭标题判断 |
| R-7.5.3 安装活动 | 安装要求适用时，包括允许外部安装 | 安装和验证接收准则；外部安装的文件化要求；组织或供方安装验证记录 | 查安装对象、要求和验证记录；不要求无安装活动产品生成虚构安装报告 |
| R-7.5.4 服务活动 | 规定有服务要求时 | 必要程序参考资料测量程序、服务验证、服务记录分析以判投诉或改进、保留记录 | 查服务安排、记录和投诉改进接口；售后电话字段不能替代服务验证程序 |
| R-7.5.5 无菌器械批记录 | 无菌器械适用 | 每灭菌批的过程参数记录及与生产批的追溯 | 查灭菌批和生产批关联及参数记录；委托灭菌仍需相应证据，抽象“已灭菌”不足 |
| R-7.5.6 过程确认 | 后续验证受限等触发条件须结合原件疑点人工核对；生产服务软件另判断 | 过程评审批准、设备人员、方法准则、适当统计抽样、记录、再确认、更改批准；软件初次使用前确认及适当变更后确认，风险相称方法与记录 | 对无争议要素查程序、计划及结果；触发条件解释标注总则来源疑点；未知不能自动免除或判缺陷 |
| R-7.5.7 灭菌及屏障系统确认 | 相应灭菌或无菌屏障过程适用 | 文件化确认程序、实施前及产品过程变更前相应确认安排、结果结论和措施记录 | 分别核对过程适用性与确认记录；不得以产品一次无菌检验替代过程确认 |
| R-7.5.8 标识 | 产品实现全过程，唯一标识按法规条件 | 文件化产品标识、监测状态、仅合格或授权让步产品使用放行、依法规唯一标识系统、退回品识别区分 | 查对象、状态、退回品及适用唯一标识安排；不默认所有市场采用同一编码方案 |
| R-7.5.9.1 追溯总则 | 按适用法规确定范围 | 文件化追溯程序、范围、方法及保持的记录 | 查追溯范围与产品、批次、活动和法规依据关系；不是仅查“可追溯”关键词 |
| R-7.5.9.2 植入器械追溯 | 植入器械适用 | 影响安全性能的组件材料及环境条件记录、分销供方或经销商记录可获得性、货运包装收件人信息 | 核对植入属性、追溯链及外部分销记录获取安排；非植入须有事实确认后排除 |
| R-7.5.10 顾客财产 | 组织控制或使用顾客财产时 | 识别验证保护维护、丢失损坏或不适用时通知顾客、保存记录 | 查财产类型和处理安排；是否包括具体资料或物品由实际输入确认，不预填真实客户资产 |
| R-7.5.11 产品防护 | 加工贮存处理销售及组成部分 | 文件化防护、避免改变污染损坏、适当包装货运容器、不足时特殊条件控制记录 | 查防护对象、包装和必要环境条件；不编造温湿度或运输限值 |
| R-7.6 监视测量设备 | 测量设备及相应用途软件 | 需求与设备、方法一致、必要校准检定与溯源、调整记录、状态、防误调与损坏、失准既往结果评价和产品措施、校准记录、风险相称软件确认及再确认 | 按设备和用途查依据、状态及记录；不默认统一校准周期；软件清单不能替代确认结论 |

## 8 测量分析和改进

| 规则编号及主题 | 对象与适用条件 | 生成要素 | 预筛条件及证据 |
|---|---|---|---|
| R-8.1 监测分析改进策划 | 体系与产品相关过程 | 证实产品符合、确保体系符合和保持有效性的监测分析改进安排，统计技术等方法及应用程度 | 查目标到方法和过程的关系；不能把“使用统计方法”口号当成具体安排 |
| R-8.2.1 反馈 | 反馈程序及生产和生产后信息 | 收集监视顾客要求满足信息、取得利用方法、生产及生产后数据、向风险和改进输入、适用法规要求的经验评审 | 查来源、利用和风险反馈接口；不只限于满意度调查或投诉 |
| R-8.2.2 抱怨处理 | 投诉程序及记录 | 及时按法规处理、接收记录、判定是否投诉、调查、报告需求、相关产品处置、纠正措施需求；不调查理由、外部信息交换和记录 | 逐项查程序，实际投诉按对象取证；没有投诉须有真实状态说明，不生成虚构投诉 |
| R-8.2.3 监管报告 | 适用法规要求报告或忠告性通知时 | 确定报告触发、通知监管机构程序、适用判定及报告记录 | 查适用法规和具体判定；不从模型记忆输出统一报告天数；无报告事件不等于程序不适用 |
| R-8.2.4 内部审核 | 内审程序、方案和记录 | 策划间隔、范围准则方法、过程状态重要性及既往结果、客观公正和不审核自身工作、实施报告、结果记录、及时纠正措施及跟踪验证报告 | 逐项核对安排与实际审核证据，独立性和时效需取证；仅有发现清单不足以完成条款检查 |
| R-8.2.5 过程监测 | 各体系过程和指标 | 适宜监视、适当测量、证明策划结果能力、未达策划结果的纠正或纠正措施 | 查过程目标、方法、结果及异常措施关系；无需为每个过程凭空生成数字指标 |
| R-8.2.6 产品监测 | 检验规程和实际记录 | 按策划阶段和程序监测特性、接收准则证据、授权放行人员身份、适当设备识别、完成安排后才放行；植入产品检验试验人员身份 | 规程查安排，记录查对象结果身份与放行关联；不能以“合格”字样代替实测和接收依据 |
| R-8.3.1 不合格品总则 | 不合格程序和记录 | 识别、文件化、隔离、评价处置职责权限、防误用交付、调查与外部通知需求、性质措施及理由记录 | 查控制链和记录关系；只有隔离标签不足以替代评价处置安排 |
| R-8.3.2 交付前处置 | 交付前发现不合格时 | 消除问题、防原预期使用、授权让步的适当路径；让步理由批准及法规条件、授权人员身份记录 | 按实际采用路径核对；不要求每件不合格品同时报废返工让步，也不允许无依据的默认放行 |
| R-8.3.3 交付后处置 | 交付或使用后发现不合格时 | 与实际或潜在影响相称措施、记录、依法规忠告性通知程序及随时实施能力、发布措施记录 | 查交付后处理及通知机制，具体召回报告义务按法规确认，不自动将所有事件定为必须召回 |
| R-8.3.4 返工 | 采取返工路径时 | 不利影响考虑、文件化返工程序、与原程序相同评审批准、返工后验证满足接收及法规、保存记录 | 查返工对象、批准程序及再验证；不得以普通维修说明或“已返工”替代验证 |
| R-8.4 数据分析 | 数据分析程序和结果 | 数据确定收集分析、统计等方法范围程度；反馈、产品符合性、过程产品特性趋势含预防机会、供方、审核、适当服务报告；不适宜等结果作为改进输入、记录 | 六类输入按条件逐项检查，查数据到结论及改进的关系；图表存在不等于分析充分 |
| R-8.5.1 改进 | 改进管理及输入记录 | 利用方针目标、审核、上市后监督、分析、纠正预防、评审识别实施必要更改，保持体系适宜充分有效及器械安全性能 | 查改进输入与实施关系；不额外引入未经依据确认的其他体系要求 |
| R-8.5.2 纠正措施 | 实际不合格及相应程序记录 | 及时消除原因防再发、与影响相称、评审含投诉、根因、需求评价、策划实施及必要更新文件、不利影响验证、效果评审、调查措施记录 | 区分即时纠正与消除原因的纠正措施；查原因到措施再到效果证据，不以完成签字替代有效性 |
| R-8.5.3 预防措施 | 潜在不合格及相应程序记录 | 识别潜在问题原因、评价预防需求、与潜在影响相称、策划实施及必要更新文件、核查措施不利影响、适当效果评审、调查措施记录 | 关注潜在问题；不得仅复制已发生问题处置；(d) 译文用词疑点转人工核对，不作精确措辞自动扣分 |
