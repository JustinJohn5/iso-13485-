# Word 草稿导出版式

模板编写的4类文档和历史修订下载统一采用用户提供的《QM-01 Rev.01质量手册》作为版式参考。下载内容仍取自所选的已保存草稿快照，排版更新不会改写数据库中的正文或修订。

## 页面与组件

- A4 纵向，页面尺寸11907×16840 twip；上、左、右边距720 twip，底边距569 twip，装订线193 twip，沿用参考件页面设置。
- 首页为组织名称、居中大标题、文件编号和版本，以及编制、审核、批准、发布和实施日期。未知人员和日期保留待填；短标题使用参考件的大字号，较长标题及标识允许换行并调整封面留白。
- 后续页面沿用四行表格页眉：文档标题、编号、版本、修改次数、生效日期、当前页与总页数；首列空白保留，未自行添加组织标志。修改次数待填，不将编写修订冒充正式修改次数。
- 更改历史沿用26行、5列的黑色网格，包含版本号、文件更改号、更改概要、修改人、批准人及文末发放范围。仅登记当前导出快照和模板版本；其余更改记录、正式更改号及人员由组织补齐。完整编写历史在网页查看。
- 目录采用带书签的章节与动态 `PAGEREF` 页码；目录后列出项目、产品、型号和编写修订／模板版本。正文为宋体12磅、1.5倍行距，一级标题按“1.0”编号，页脚保留参考件分隔线并标注草稿修订。

长编号、长版本在狭窄页眉或更改历史单元格显示“详见封面”（最窄版本格简写为“见封面”），封面保留完整内容。正文不因排版截断，长段落允许自然跨页，表格表头可重复、行高允许增长。

页码、总页数及目录使用 Word 动态域，设置了打开时更新。在 Word/WPS 中若显示“待更新”，请更新全部域（Word：`Ctrl+A` 后按 `F9`），再检查打印预览；手工编辑后亦应更新。服务端无需安装 Word 或 LibreOffice，DOCX 导出不依赖办公软件。

## 模板与维护

`backend/App/Assets/Documents/ManualLayout.docx` 是从参考件复制并清理的独立版式资产，随后端代码一起部署。保留来源的样式、编号、主题、页眉表格和页脚线；移除原手册的业务条款、原日期、签署内容及自定义 XML/个人属性。封面原空段和浮动横线改为段落间距与下边框，以适配不同标题和组织名称；原黄色标注已清除。

资产封面使用 `{{company}}`、`{{title}}`、`{{number}}`、`{{version}}` 文本槽；导出器填入网页已保存参数。`WordExport.py` 编排内容，`WordLayout.py` 处理样式、单元格与动态域。模板位置通过模块路径解析，macOS、Ubuntu 和 Windows 均无需原参考件路径或新环境变量。

修改版式时须同步检查模板资产与导出代码，运行 `tests/Services/test_WordExport.py`、模板测试和 Word 下载 E2E，并渲染四类样稿及跨页长文检查封面、页眉、目录、表格和正文。不要用参考件中的业务条款填充用户草稿。
