# 个人中心与管理后台设计

2026-11-26 用户已确认聊天中的整体设计，本文将确认内容固化为实施合同。

## 页面与权限

前台移除所有模型配置入口以及侧栏改密入口。右上角账户菜单包含已上传文件、文件分组、修改密码；管理员额外显示后台管理。菜单支持键盘、Escape 与外部点击关闭。个人文件只展示本人的上传记录，即使当前账号是管理员。

后台采用同站独立入口 /admin/，单独页面与导航，复用现有认证和模型配置接口。后台包括概览、访客状态、模型配置、服务器日志、操作记录；普通账号不能读取后台数据。未登录显示登录，非管理员显示无权限和返回工作区。

## 个人文件与分组

文件支持名称搜索、类型及分组筛选、分页、下载原件、选择不超过20份加入当前预筛。数据库存储已有文件引用，不重新上传。分组支持创建、重命名、删除以及批量添加/移出成员；文件可属于多个组，删除组不删除文件。分组按用户隔离，同名组返回冲突；成员变更批量校验所有权并事务提交。保留历史审核引用。

## 访客口径

用户选择匿名访客与登录用户同时统计。服务端签发 HttpOnly 随机访客 Cookie，不存原始 IP、查询字符串或认证信息。页面首次展示及功能切换计访问量，页面可见时每60秒心跳；5分钟内有心跳视为在线。登录前后同一 Cookie 只算一个访客；退出后心跳清除登录身份。统计日期使用既有 Asia/Shanghai 时间工具。数据来自新功能启用后，历史空数据展示为0。

## 日志与运行状态

管理员只读获取应用的 App.log / Error.log 及受控轮转文件，接口不接受任意路径，读取字节数和返回行数有界。按级别、日期、关键词、请求编号筛选，脱敏后展示；文件不可用时明确报错。概览查询 API/数据库连通性及访客聚合。操作记录复用现有 audit_logs，并补充本次登录登出、分组变更等动作。不得显示密钥、Cookie、用户正文或数据库连接串。

## 交付与验证

沿用 TypeScript/Vite、Python3.12.10/FastAPI/SQLAlchemy、MySQL8.4，不新增框架。新增版本化迁移，在 _codextest 副本验证后应用开发库；不修改正式库。核心路径、越权、菜单和窄屏用 Playwright 验证，服务逻辑用 pytest；所有测试在 tests/ 下。维护 README、deploy、CHANGELOG、测试说明。保留任务开始前未提交改动，只提交本次修改。
