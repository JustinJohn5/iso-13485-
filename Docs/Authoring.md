# 模板编写与模拟内审操作说明

本功能按“模板检索 → 参数化草稿 → AI 或人工编写 → 修订与导出 → 预筛及模拟内审”使用。生成文件始终是草稿，须按组织要求复核、批准和发布。

## 模板检索与生成

1. 登录后点击“模板与编写”，按关键词或分类查找模板。
2. 当前提供市场调研报告、成品检验规程、设计开发计划、文件控制程序4种项目自有示例，并非官方标准文件或完整合规模板。
3. 填写组织、项目、产品、型号、文件编号、文件版本以及实际要求，点击“生成文档草稿”。未知的检验限值、调研数据等不要编造，可在要求中写明待确认。
4. 在正文预览中逐章修改，填写至少5字的变更原因，点击“保存正文修订”。
5. “下载 Word 草稿”统一输出标题、参数表、章节、人工批准占位及页码。下载的是已保存版本，下载前应保存所需编辑。
6. “版本与变更记录”可查看理由、操作者、时间并下载旧修订。每份草稿最多保留50次修订；达到上限时新建草稿。

更新参数会按原模板重新生成全文，覆盖当前人工或 AI 正文；原修订保留。多人同时编辑时，过期版本会被拒绝，点击“重新加载已保存版本”后重新处理；重新加载会丢弃当前未保存编辑。

## 跨文档参数联动

点击“跨文档参数联动”，展开面板并选择1～20份草稿，只填写需要统一的组织、项目、产品或型号以及变更原因。
“预览联动影响”展示每份草稿旧值、新值及新修订号，不修改文件。确认影响后点击“按预览应用并保存新修订”。修改选择或参数后需重新预览。

联动会按每份草稿模板重新生成正文，保留独立文件编号、文件版本和其他参数；人工与 AI 正文将被新模板结果替代，旧修订仍可下载。
只影响所选草稿，不修改上传原件、组织正式发布文件或历史预筛快照。任一文件版本过期、权限不足或参数非法时整批拒绝，不部分更新。

## 模型配置与 AI 编写

管理员通过“模型配置”维护 OpenAI 兼容服务地址、模型、API Key、单次超时、最大输出 token 和温度，并启用。
API Key 加密保存，只显示是否已配置；留空保留密钥，更换服务地址时须重新提交密钥。审核员仅能看到模型是否就绪。

打开已保存草稿，填写至少5字的编写要求，再点击“按已保存草稿进行 AI 编写”。此操作向配置的服务发送已保存正文、参数和要求，覆盖章节并保存新修订；未保存的编辑不作为 AI 输入。
模型输出、数值、事实、引用和待确认事项都要人工复核。超时、服务错误、缺章或异常 JSON 会保留原草稿，可继续人工修改。
配置未完成时仍可使用模板与预筛；部署密钥解密失败时由管理员重新提交 API Key。

### 长文本容量

产品资料和模板要求最多100,000字符，AI 编写要求最多30,000字符，每个正文章节最多120,000字符。
单次模型总输入（系统提示及序列化后的参数、章节、要求）最多1,000,000字符；输出响应最多400,000字符。应用不会静默截断资料或正文，超限时明确拒绝，原草稿保留。
“模型配置”允许最大输出256～65,536 token、单次超时5～600秒；最多重试1次。更新程序后已有配置值保留，可按模型能力在网页调高。
字符数不等同于 token 数，应用容量也不等同于模型上下文窗口。实际输入与输出合计仍受所选模型窗口约束，最大输出还受服务商限制；调高应用限制不能扩大模型本身的容量。
长文生成时反向代理的读取超时也应覆盖实际请求时长，必要时考虑一次重试；上限600秒指每次 SDK 请求的超时配置，并非整个任务的总时限。

## 模拟内审清单

将完成复核的文档按既有流程上传，处理正式版及关联依据后运行预筛。在结果下方点击“生成内审问题清单”。

- 规则缺项：追问原件或配套记录中是否存在未提取到的内容。
- 引用待核对：提示提供本批次缺少的受控版本并核对引用。
- 跨文件冲突：展示不同原文和取舍、修订、引用更新问题；选择本次依据不会消除源文件矛盾。
- 实施取证：即使文本通过，也要求展示实际执行、复核与追溯记录。

清单基于已保存预筛证据，不重新调用模型，不改变分数。Word 导出预留责任人、计划日期、实际证据及有效性验证字段。
已有任务同类型多文件时，相关文件显示范围，不能据此推断原文证据唯一属于某份文件。清单属于内审准备材料，不替代正式审核与不符合项定性。

## 当前边界

模板库随代码版本维护，尚未提供网页上传任意 Word 模板、模板审批发布、跨批次永久审核项目、OCR 或完整标准语义审核。现有规则仅覆盖已登记文本线索；AI 不自动作符合性判定。
草稿修订及参数联动不等同于组织正式文件控制流程。任何待确认的事实、限值、批准、生效及法规依据均应由授权人员据实核实。
